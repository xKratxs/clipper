Clipper

Pega un link de YouTube: encontramos los mejores momentos y les ponemos subtítulos. Se procesa en GitHub, así que puedes cerrar esto y volver luego.

Opciones
Crear clips en GitHub

Se abre GitHub: pulsa Run workflow, pega el link y confirma. O conecta este dispositivo para crear clips desde aquí mismo.

Conectar este dispositivo no conectado
  1. En GitHub: foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories y este repositorio.
  3. En Permissions: Actions = Read and write, Contents = Read and write.
  4. Copia el token y pégalo aquí. Se guarda solo en este navegador.
